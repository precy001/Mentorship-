Mentorship+ API network fix

1. Extract this ZIP into the root of your existing Mentorship+ project.
2. Allow it to replace src/lib/api.ts only.
3. From the project root, run:
   npx tsc --noEmit
4. If typecheck passes, commit and push src/lib/api.ts.
5. Publish a new OTA update to the preview channel:
   npx eas-cli@latest update --channel preview --environment preview --message "Use Expo native fetch for API requests"

What changed:
- JSON API requests now use the same Expo native fetch implementation already used by the profile-picture upload.
- Network errors retain the original error name/message in the sign-in alert and diagnostic log, instead of hiding the underlying cause.

This patch does not change screens, API routes, authentication payloads, or the Render URL.
